# design-systems

Drop `.md` design-style files here. Each file should describe one visual style/brand system
so it can be picked up and applied when building websites, interfaces, or other visual work.

## File format

Start each file with frontmatter so it can be matched to the right task:

```markdown
---
name: short-kebab-case-name
description: One line — what this style is and when to use it (triggers, keywords, project types)
---

(rest of the file: full design system — colors, type, spacing, tone, components, do/don't rules)
```

Name the file to match `name:` (e.g. `industrial-brutalist.md`).

## Usage

Just say which style to use, or describe the project and ask me to pick the best match from
this folder — I'll read the relevant file(s) before building.
